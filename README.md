# 🤖 College FAQ Chatbot

An NLP-based **FAQ Chatbot** built with Python and Streamlit as part of the **CodeAlpha Artificial Intelligence Internship**.

The chatbot allows users to ask questions related to college admissions, courses, fees, scholarships, hostel facilities, placements, internships, and other common college-related topics.

The system uses **Natural Language Processing (NLP), TF-IDF Vectorization, and Cosine Similarity** to identify the most relevant FAQ and provide an appropriate response.

---

## 🚀 Features

- 🤖 Interactive chatbot interface
- 💬 Natural language question input
- 🧠 NLP-based text preprocessing
- 🔤 Tokenization and text cleaning
- 📊 TF-IDF vectorization
- 📐 Cosine similarity-based FAQ matching
- 🎯 Best matching answer selection
- 📈 Match confidence display
- ⚠️ Fallback response for unsupported questions
- 🗑️ Clear chat functionality
- 📚 FAQ categories in sidebar
- 💻 User-friendly Streamlit interface

---

## 🧠 How It Works

The chatbot follows this workflow:

```text
User Question
      ↓
Text Preprocessing
      ↓
Tokenization
      ↓
TF-IDF Vectorization
      ↓
Cosine Similarity
      ↓
Find Most Similar FAQ
      ↓
Confidence Check
      ↓
🤖 Chatbot Response
